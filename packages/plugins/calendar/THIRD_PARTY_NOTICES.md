# Third-party notices

## Timor holiday API

The Calendar plugin retrieves mainland China public-holiday and adjusted-workday
data from the hosted [Timor holiday API](https://timor.tech/api/holiday/).

The service is free to use without registration and documents a limit of 10,000
holiday API requests per IP address per 24 hours. The Timor website publishes
its content under the
[Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International
License](https://creativecommons.org/licenses/by-nc-sa/4.0/).

Steward is not affiliated with Timor and does not redistribute the API's
server-side source code. Calendar stores fetched yearly responses locally to
reduce load on the service and silently omits badges when data is unavailable.
