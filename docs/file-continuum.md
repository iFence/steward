# 文件对话框文件连续体（Windows）

打开／另存为对话框出现时，Steward 搜索框会自动显示在对话框正下方并接管键盘焦点，可直接输入要跳转的目录；搜索框始终与对话框等宽。

## 使用方式

1. 在资源管理器打开目标文件夹，例如 `D:\项目\资料`，让该窗口保持前台至少半秒。
2. 切到应用的打开／另存为对话框。Steward 识别到对话框后自动在它正下方显示搜索框，宽度与对话框一致，并预填最近活动的资源管理器目录；**键盘焦点自动进入搜索框**，可直接输入或修改目录，无需再点一下，也不会输入到对话框自带的路径／文件名编辑框。移动或调整对话框大小时，搜索框跟随位置和宽度变化。
3. 想继续操作原对话框（点击文件名或目录列表）时直接点击它即可；搜索框保持贴附，状态提示“点击搜索框开始输入”，点击搜索框可再次接管输入。
4. 保留预填路径，或修改／清空它重新查找；用上下键选择目录，按 Enter 让原对话框跳转。
5. 按 Esc 取消，返回原对话框。完成、取消或切走窗口后，Steward 恢复进入前的搜索文字。只要文件对话框重新获得焦点，搜索框就会再次自动贴出（此时不抢焦点，点击它可继续输入）；完成或取消后焦点返回原对话框，也会重新贴出。

Enter 只切换目录；打开文件或确认保存仍由用户在原对话框中完成。输入区下方会提示点击输入、搜索、导航或错误状态。查询尚未完成时不能确认旧结果。

## 可以查找哪些目录

| 输入 | 候选来源 |
| --- | --- |
| 保留预填路径 | 该目录及其直接子目录 |
| 清空 | 本次运行记录的最近目录和常用目录 |
| 目录名、关键词或拼音 | 在最近目录和常用目录中模糊匹配 |
| 完整或部分绝对路径，例如 `D:\项目\资` | 已存在的对应目录，或父目录中匹配的直接子目录 |

历史最多保留 50 个目录，重启后清空。尚未观察到资源管理器目录时，搜索框为空，仍可手动查找。此功能不建立全盘文件索引，也不递归搜索任意磁盘中的文件夹。

单次最多显示 32 个结果，浏览子目录时最多检查 256 个直接条目（包括文件）。超大目录的候选可能不完整，可直接输入目标目录的完整路径。

## 支持范围与限制

- 仅适用于 Windows 资源管理器的文件系统目录，以及带 Shell 文件视图和地址栏的现代标准打开／保存对话框。第三方文件管理器、自定义／旧式对话框及“此电脑”等虚拟目录不在本次支持范围。
- 搜索框始终贴在对话框正下方、与对话框水平对齐并保持相同宽度，结果列表在下方展开。对话框移动或调整大小时同步更新；不会为了避开屏幕边沿而移到对话框上方或缩窄。对话框关闭或切走后自动隐藏，重新获得焦点时再次贴出。键盘焦点只在某个对话框首次出现时自动进入搜索框；之后重新贴出时交给对话框保持焦点，点击搜索框才接管输入。若系统拒绝焦点转移（例如目标对话框属于管理员权限进程），首次出现也会退回点击输入提示。
- 每 250 ms 采样前台资源管理器；很快切换窗口可能尚未更新历史。实现读取可见活动视图，Windows 11 多标签页的实际行为仍需按下表验证。
- 目标对话框已关闭、焦点被其他窗口抢走、目录失效或访问被拒绝时，导航可能失败；不会退回到修改文件名或自动点击保存的方式。普通权限 Steward 对管理员程序的对话框兼容性未保证。
- UNC／离线网络目录的读取受系统和网络响应影响，可能延迟目录结果；文件系统查询在工作线程执行。消息成功发送不代表目标应用已经完成目录切换，应以原对话框显示为准。
