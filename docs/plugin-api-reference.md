# Steward Plugin API Reference

> Generated from `contracts/plugin-api-v1.json`. Do not edit this file directly.
> Run `pnpm contract:generate` after changing the contract.

Host API version: `1.1.0`. Contract version: `2`.
Stable API line: `1.x`. Minimum supported host API: `0.3.0`.

This reference covers the command-oriented Steward bridge. NSH UI primitives and
standard NSH modules are documented separately in [nsh-plugin-api.md](nsh-plugin-api.md).

## Versioning

- Patch: Patch releases may fix implementation behavior but cannot remove calls, fields, events, or capability scopes, and cannot change their meaning.
- Minor: Minor releases may add calls, optional request fields, optional response fields, events, features, and capability scopes. Existing stable inputs and successful responses keep their meaning.
- Major: A major release may remove or change stable behavior only after the documented deprecation window and an explicit migration line.
- Deprecation: A deprecated public entry remains available for at least one minor release in the current major line. Its contract record must name the replacement and the first removal version. Removal happens only in a later major release.

## Failure Semantics

Every API family maps the same failure states to stable codes: `disabled` -> `feature_unavailable`, `revoked` -> `permission_denied`, `expired` -> `permission_denied`, `malformed` -> `invalid_input`, `timedOut` -> `timeout`, `cancelled` -> `cancelled`, `resourceExhausted` -> `resource_exhausted`.
A rejection is delivered as the versioned JSON error envelope documented in
[plugin-api-contract.md](plugin-api-contract.md). Plugins must branch on `code`, not prose.

| State               | Code                  | Meaning                                                                                   |
| ------------------- | --------------------- | ----------------------------------------------------------------------------------------- |
| `disabled`          | `feature_unavailable` | The running host does not provide the requested API family.                               |
| `revoked`           | `permission_denied`   | No active capability grant matches the plugin, publisher, version, permission, and scope. |
| `expired`           | `permission_denied`   | A previously active resource grant or package-version grant no longer matches.            |
| `malformed`         | `invalid_input`       | The request fails schema, range, path, or semantic validation.                            |
| `timedOut`          | `timeout`             | A bounded host operation exceeded its deadline.                                           |
| `cancelled`         | `cancelled`           | The plugin or user cancelled the operation before completion.                             |
| `resourceExhausted` | `resource_exhausted`  | The request or API family exceeded a payload, queue, concurrency, or output quota.        |

## Stable Errors

| Code                  | Retryable | Meaning                                                                        |
| --------------------- | --------- | ------------------------------------------------------------------------------ |
| `permission_denied`   | no        | The package declaration or an active grant does not authorize the request.     |
| `feature_unavailable` | no        | The running host does not provide the requested feature or API family.         |
| `timeout`             | yes       | A bounded host operation exceeded its deadline.                                |
| `resource_exhausted`  | yes       | A payload, output, queue, concurrency, or platform quota was exceeded.         |
| `host_failure`        | yes       | Steward could not complete the host operation.                                 |
| `invalid_input`       | no        | The request failed schema, range, path, or semantic validation.                |
| `cancelled`           | yes       | The operation was cancelled before completion.                                 |
| `confirmation_denied` | no        | The user declined a host-rendered confirmation.                                |
| `io_failure`          | no        | A filesystem or system-open operation failed at the operating-system boundary. |
